# Diego Fiatt Portfolio

Static portfolio and project inquiry site for Diego Fiatt.

## Local preview

Open `index.html` directly or serve this folder with any static file server.

## Deployment

This repository is intended for GitHub Pages. In GitHub, set **Settings → Pages → Deploy from a branch**, choose `main`, and select `/(root)`.

The inquiry form is deliberately client-side: it opens the visitor's email app with a complete request. It does not store contact data or expose credentials. Replace it with a server-side form provider only after configuring its secret or verified endpoint outside the repository.
